SETTINGS

Sirf English akshar, ek shabd, 3 se 12 akshar. Shabd Vosk model ki dictionary mein hona chahiye (jaise nova, jarvis, computer). Na mila to NOVA khud "nova" use karega aur bata dega.
NOVA pehle local phone actions karta hai. AI request mein configured model fail/quota par available fallback try hota hai. Monitoring phone ke andar hi chalti hai (Accessibility text, koi image nahi) aur kuch bhi cloud par nahi bhejti. Iske liye Accessibility ON honi chahiye. Screen ka analysis alag hai: sirf jab aap bolo "analyze screen"; key hone par hi password-free screen text AI ko jaata hai.
Bina key ke phone commands (torch, volume, battery, apps...) offline chalte hain. Key sirf lambe sawaal, web search aur deep screen analysis ke liye chahiye. Keys Android Keystore mein encrypted rehti hain aur kabhi screen par wapas nahi dikhti. Quota/server error par NOVA agli saved key/model try karta hai. Sirf apni/authorized keys rakho.
Optional. Home/Back/Recents/Notifications jaise navigation, WhatsApp auto-send (sirf aapke "yes" ke baad) aur local screen monitoring ke liye. Bina Accessibility ke baaki phone controls chalte rehte hain. NOVA screen text apne aap cloud par upload nahi karta.
Android 13+ par pehle APP INFO mein jao, upar teen dot (⋮) dabao, "Allow restricted settings" chuno. Phir ACCESSIBILITY ON KARO mein NOVA ko ON karo.
Ye sirf tab maange jaate hain jab aap yahan tap karo. Contacts: "naam ko call/message karo" ke liye. Brightness: screen ki roshni badalne ke liye.
