## Design decisions already taken (keep them)
1. The knowledge data is a NEW bundled file app/src/main/assets/knowledge.json: {"title","version","entries":[{"id","q":[variants],"hi":"Hinglish answer","en":"English answer","tags":[..]}]}. It is NOT put in skillpacks/starter.json because that file is the action-shortcut format (name/triggers/steps) read by build_feed.py and Updater (max 100 skills, 200 KB). Do not touch skillpacks/.
2. Source files live in tools/knowledge_src/k_*.py as `E = [(id, [variants], hi, en, [tags]), ...]`. A script tools/build_knowledge.py merges them into the asset (sorted, unique ids, json with ensure_ascii=False).
3. Matcher rules (already in KnowledgeMatcher.kt): content tokens = lowercase a-z0-9 words minus STOP, spelling variants unified by CANON, plural "s" stripped; score = 200*matched/(userTokens+entryTokens) integer; best entry needs >= 60; a different entry within 5 points = tie = null; >=2 shared tokens, or one shared token only for a one-concept question (1 content token, entry variant of <=2 tokens, >=2 raw words); one typo forgiven only for words of 6+ letters; any LIVE word (aaj, abhi, today, now, news, price, score, dollar, gold, ...) = null; text > 160 chars or > 14 words = null. Answer by language: cfg.lang == "en" -> en, else hi. Text only, never an action.
4. Wiring place (decided): in NovaService.handle, AFTER `c` (classify / shortcut / groq text) is still null and BEFORE `brain.record(... "unknown")`, so a knowledge question is not logged as "unknown" (Brain may build shortcut proposals from unknowns). Use `said` = groqText if present else text; skip when Logic.isJunk(text) (and groqText blank). On a hit: lastTurnLocal = true; lastKind = "knowledge"; brain.record(now, text, "local", "knowledge"); return the answer. This runs before the offline-model translator (Layer 2) and before Gemini / free chain.
5. Logic.classify runs first, so commands always win. KNOWN SHADOWING: classify catches battery/charge (<=6 words), time/date (<=5 words), torch, volume, brightness, screen+(kya/dekho/...), timer/alarm, wifi/bluetooth (<=3 words), open/kholo, tap, scroll, type, monitor, "yaad rakh", "driving mode". LocalSkills catches calc, unit convert, date maths, emergency numbers and first aid for snake / nosebleed / burn / bleeding-cut-wound-zakhm. Knowledge variants must avoid these words (the validator must flag them), and entries must not duplicate those skills.
